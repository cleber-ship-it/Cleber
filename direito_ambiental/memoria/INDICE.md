# Memória de pesquisas — índice

Cada pesquisa/parecer/auditoria relevante gera um arquivo em `pesquisas/` (template `templates/PESQUISA_MEMORIA.md`).
Este índice é mantido manualmente pelos comandos (uma linha por pesquisa; mais recente no topo). Uma versão gerada
automaticamente está em `indices/memoria.md`.

MEMÓRIA ≠ VERDADE ATUAL: antes de reutilizar uma conclusão, verificar `validade_estimada` e o nível de verificação.
