# Resposta jurídica — formato padrão

**DATA DAS FONTES:** AAAA-MM-DD | **NÍVEL DE VERIFICAÇÃO PREDOMINANTE:** FONTE_PRIMARIA / INDIRETA / NAO_VERIFICADA
**TERRITÓRIO:** município/UF | **ATIVIDADE:** | **ÓRGÃO COMPETENTE (hipótese):**

## QUESTÃO
Descrição objetiva do problema.

## RESPOSTA DIRETA
SIM / NÃO / DEPENDE / NÃO HÁ PREVISÃO EXPRESSA / HÁ CONTROVÉRSIA JURÍDICA — uma frase.

## FUNDAMENTO LEGAL
Para cada norma: nome, número, artigo, parágrafo, inciso, redação aplicável (entre aspas apenas se
conferida), data, link oficial, status de vigência e nível de verificação.
Separar: **TEXTO EXPRESSO** ≠ **INTERPRETAÇÃO**.

## INTERPRETAÇÃO
Alcance jurídico. Indicar hierarquia/competência/especialidade quando relevante.

## JURISPRUDÊNCIA
Precedente identificado (tribunal, órgão, número, relator, data, link). Se não localizado: dizer.

## APLICAÇÃO AO CASO
Relacionar regra ao fato. Premissas técnicas: confirmadas (por quem) ou HIPÓTESE A CONFIRMAR.

## RISCO JURÍDICO
BAIXO / MODERADO / ELEVADO / MUITO ELEVADO — e por quê.

## ARGUMENTO CONTRÁRIO
Como o órgão ambiental / Ministério Público / parte contrária contestaria. Resultado da revisão adversarial.

## CONCLUSÃO
Objetiva. **CONFIANÇA:** ALTA / MÉDIA / BAIXA (fatores). Natureza de cada comando: OBRIGAÇÃO LEGAL /
ENTENDIMENTO JURISPRUDENCIAL / EXIGÊNCIA ADMINISTRATIVA / BOA PRÁTICA.

## LACUNAS
Exatamente QUAL informação impediria conclusão definitiva (norma municipal não levantada, dado técnico, etc.).
