# Outros Estados

O núcleo deve ser capaz de analisar qualquer UF. Perfis e fichas seed existem para RS, SC, PR, SP, MG, MT, MS, GO, RJ, PE, PB, ES, CE, BA e PI (`estadual/<uf>/PERFIL.md`). Para UF nova: Procedimento:
1. Identificar UF → Constituição Estadual, Código/Política Estadual de Meio Ambiente, lei de recursos hídricos,
   resolução do Conselho Estadual sobre impacto local (LC 140 art. 9º XIV), órgão licenciador, portal de legislação.
2. Criar subpasta `estadual/<uf>/` e fichas via `/registrar-norma` (mesmo template).
3. Registrar fontes oficiais da UF em `fontes/FONTES_OFICIAIS.md`.
Portais de partida (secundários, para localização): legisweb.com.br; leisestaduais.com.br; sites das Assembleias.
